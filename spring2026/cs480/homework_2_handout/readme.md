# Homework 2

## Solve the homework

- **Do not rename the sql files as they are graded automatically.**
- **The submitted zip file cannot have subdirectories.**

Answers to the SQL questions should be entered into the `.sql` files. The autograder uses PostgreSQL 14 ([https://www.postgresql.org/](https://www.postgresql.org/)).

The file `homework_2.sql` contains SQL code for generating the schema and loading the test data.

## Prepare and upload solutions

To upload your solution to gradescope, create a single archive named `submission.zip` containing all of your files. You can use the makefile in this directory from this directory to do that:

```sh
make
```

Once you have a `submission.zip` file, you can upload it through gradescope's webinterface. After the autograder is done it will provide you with feedback about your solutions. That is, it will tell you how your query results differ from the expected query results.

**The sql files have to be in the main folder of the archive for the autograder to be  able to find them.**
